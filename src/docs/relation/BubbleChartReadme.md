# Bubble Chart

A bubble chart in Python extends a standard scatter plot by mapping data values to the size and color of markers, allowing you to display up to four dimensions of data simultaneously. [1] (https://www.youtube.com/watch?v=9YKleQCVnFI&t=1789), [2] (https://python-graph-gallery.com/bubble-plot/)

## What is a Bubble Chart Used For?

Multivariate Analysis: Comparing two primary numerical variables (X and Y) while encoding a third variable via bubble size (Z) and a fourth via color. [1](https://python-graph-gallery.com/bubble-plot/), [2] (https://www.youtube.com/watch?v=9YKleQCVnFI&t=1789)
Identifying Trends: Spotting clusters, outliers, and proportional differences in large datasets (e.g., comparing population, GDP, and life expectancy across countries). [1] (https://www.kaggle.com/code/aashita/guide-to-animated-bubble-charts-using-plotly), [2] (https://plotly.com/python/bubble-charts/)Business & Financial Dashboards: Displaying project risk vs. reward (axes) with bubble size representing budget impact and color representing department. [1] (https://www.geeksforgeeks.org/data-visualization/bubble-chart-using-plotly-in-python/)
